# Install and update DubiSub

[Tiếng Việt](install.vi.md) · [User guide](user-guide.md) · [Help](support.md)

1. Download **DubiSub-Setup-vX.Y.Z.exe** from [the latest release](https://github.com/DubiLabs/dubisub-releases/releases/latest). The installer targets Windows 10/11 x64. Check the release notes for hardware and signing details. Compare the download with the accompanying SHA-256 if needed.
2. Run the installer and open DubiSub from Start. Use **Settings → Resource Packs** to install the recommended runtime and models.
3. Start a project with the [user guide](user-guide.md). See [account and activation](account.vi.md) for paid plans and license keys.

The updater and resource manager handle Core, engine and split archives. For a manual update, finish running jobs, close DubiSub and run the new official installer over the current installation. Back up important projects first.
